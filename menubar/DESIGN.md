# CC Menubar 디자인 (시각 SSOT)

메뉴바 패널의 화면을 바꿀 때는 이 문서를 먼저 고치고, 같은 PR에서 코드(`Sources/TeamClaudePalette.swift`, `Sources/DashboardPanel.swift`)를 맞춘다.
출처는 2026-10-24에 고른 웹 시안 A안이다. 시안은 참고 자료이고, 이 문서와 코드가 정본이다.

## 원칙

- "지금 쓸 수 있나"에 먼저 답한다. 개요 탭 맨 위가 지금 라우팅 가능한 계정 수다.
- 바탕은 거의 검정인 무채색이다. 상태색(민트·호박·빨강·하늘)은 점, 짧은 라벨, 막대 상태에만 쓴다. 면을 상태색으로 칠하지 않는다.
- 높은 사용률은 실패가 아니다. 이 풀의 목표 사용률은 100%다(`SubscriptionPolicy.swift`). 막대는 98% 라우팅 문턱부터만 호박색이고, 그 아래는 밝은 회색이다. 예전의 70% 노랑·90% 빨강은 쓰지 않는다.
- 막대 위 하늘색 세로 눈금은 창이 지난 비율이다. 채움이 눈금보다 앞서면 그 창은 리셋 전에 찬다.
- 숫자와 계정 이름은 고정폭 숫자(`monospacedDigitSystemFont`, 계정 이름은 `monospacedSystemFont`)로 그린다.
- 단축키는 키캡 칩으로 보인다.
- 기능을 숨기지 않는다. 섹션은 탭 5개에 나눠 담고, 동작은 하단 막대와 동작 목록(⌘K)에 모은다.

## 패널 구성

- 폭 520pt. 높이는 개요 탭의 자연 높이(본문 최소 400pt, 화면 높이 이하)로 정한다. 그보다 긴 탭(계정이 많은 Claude 탭 등)은 탭 본문만 안에서 스크롤한다. 머리와 하단 막대는 움직이지 않고, 메뉴가 열려 있는 동안에는 높이를 바꾸지 않는다.
- 머리: 앱 표시, 제목 "TeamClaude 사용량", 기준 시각("10/24 23:46 기준"), 오른쪽에 "손볼 것 N" 배지(호박 점). 배지를 누르면 개요로 간다.
- 탭 5개 세그먼트: 개요 · Claude · Codex · 소진 · CLI. 숫자 키 1–5로도 옮긴다.
- 하단 막대: 왼쪽은 지금 탭의 한 줄 요약, 오른쪽은 "새로고침 R"과 "동작 ⌘K". 동작 목록에는 계정 측정, 계정 가져오기·추가, 서버 재시작, 로그인 시 열기, 종료가 있다.

## 막대

- 트랙: 흰색 8%, 높이 6pt, 둥근 끝.
- 채움: 정상 ash 85%, 98% 문턱 이상 amber, 라우팅에서 빠진 계정 graphite.
- 창 경과 눈금: sky 2pt 폭, 트랙보다 위아래로 1pt 길고 sheet 색 테두리를 둔다. 빠진 계정에는 그리지 않는다.
- 값 글자: 고정폭 12pt. 다 차지 않은 값은 99%에서 멈춘다(99.5%를 100%로 보이지 않는다).

## 개요 상태별 목록

2026-10-27 웹랩 시안 A("상태별 목록")를 옮겼다. 계정마다 지금 세션(5시간 창)이 얼마나 찼고 언제 풀리는지를 먼저 보인다. 묶음과 수는 큰 숫자와 같은 라우팅 판정(`routingAvailability`)에서 나온다.

- 큰 숫자 옆: 머리 문장, 상태별 수(범례 색 점: 사용 가능 mint · 대기 amber · 제외 ember, 일시 대기는 0이면 숨김, 폭이 모자라면 0인 대기 항목부터 뺀다), "다음 복귀 <계정> <남은 시간> 뒤 · <시각>"(기다리는 계정이 없으면 다음 리셋 줄).
- 지금 받는 계정(세션 많이 찬 순, 최대 6칸 + "외 N개 · Claude 탭에서 전부"): 칸마다 세션 막대(높이 8pt, 안의 sky 눈금 = 5시간 창이 지난 비율)와 세션 퍼센트(15pt medium 고정폭 숫자), 오른쪽에 리셋까지 남은 시간과 리셋 시각. 아래 줄에 주간·Fable 작은 막대(높이 4pt)와 퍼센트·남은 시간. 동시 요청이 가득 찬 계정은 이름 아래 "사용 중 3/3".
- 속도 경고: 창이 15% 이상 지났고 지금 속도(세션 사용률 ÷ 지난 비율)면 리셋 전에 98%에 닿을 때만 호박 삼각형과 한 줄 "지금 속도면 약 X 뒤 98% · 리셋보다 Y 이름". 이미 98% 이상이면 막대가 호박색으로 말하므로 줄을 그리지 않는다.
- 복귀 대기(빨리 풀리는 순, 5줄 + "외 N개 · Claude 탭에서 전부"): 상태 점, 이름, 원인 태그(무채색 면). 판정의 막힌 창에 주간이 들었으면 "주간 가득"(복귀 = 주간 리셋), 세션만이면 "세션 가득"(복귀 = 세션 리셋, 주간 작은 막대를 곁들인다), 막힌 창이 없으면(일시 제한·확인 필요) "일시 대기"로 복귀 시각 대신 상태 라벨을 보이고 맨 뒤에 둔다. 5시간 안에 돌아오는 남은 시간은 fg로 밝게.
- 제외: 0이면 그리지 않는다. 손볼 것에 이미 있는 계정은 다시 그리지 않고 머리 오른쪽에 "N개는 아래 손볼 것에"라고만 쓴다. 나머지(구독 종료 등)는 이름과 사유(`teamClaudeRowPresentation` 라벨) 한 줄씩.
- 칸·줄을 누르면 그 계정의 Claude 탭 행, "외 N개" 줄은 Claude 탭. 높이는 접기 규칙 덕에 계정 수(100·250)와 무관하게 위 상한에서 멈춘다.

## 구독 상태

2026-10-28 웹랩 시안 B 2차본("기존 탭 안에 더하기")을 옮겼다. 새 탭을 두지 않고 Claude·Codex·개요 탭에 더한다. 판정은 `Sources/SubscriptionState.swift`, 처리는 `Sources/SubscriptionActions.swift`, 기호·버튼·대화상자는 `Sources/SubscriptionPanelUI.swift` 한 곳이다.

| 상태 | 기호(11pt, 모양이 뜻을 갖는다) | 라벨 색 | 규칙 한 줄 |
|---|---|---|---|
| 구독 중 | mint 원 + sheet 체크 | mint | 결제·청구 화면이나 확인 메일로 확인한 기록이 있음 |
| 확인 안 됨 | fg3 점선 고리 | fg3 | 기록 없음 · 인증 오류만으로는 해지인지 알 수 없음 |
| 해지 예약 | sky 고리 + 종료일로 갈수록 차오르는 sky 파이(12~92%) | sky | 종료일까지 사용 가능 · 다음 인증 실패 때 종료로 확정 |
| 종료일 지남 | amber 원 + sheet 느낌표 | amber | 종료일이 지났지만 아직 종료로 확정되지 않음 |
| 해지 확정 | fg3 원 + sheet × | fg3 | 순환에서 빠짐 · 재인증 대상 아님 |

- 종료일 당일까지는 해지 예약, 다음 날부터 종료일 지남이다.
- Claude 탭: 이름 바로 옆에 기호(기호 자리만큼 이름 폭을 줄인다). 해지 예약 줄에는 "N일 남음"을 붙인다. 펼친 행 맨 위에 구독 기록 세 줄(16pt 간격): "상태"(기호 · 라벨 · 종료일 · 남은 날), "근거"(근거 · 기록 시각), 이 맥 기록과 프록시 값이 다르면 amber 한 줄로 둘 다, 같으면 규칙 한 줄. 펼친 상세는 그만큼(52pt) 높다.
- Claude 상태 칸: 해지 기록이 있는 인증 오류 계정은 "재인증" 대신 primary "종료로 확정". 누르면 행을 펼치고 펼친 행의 확정 버튼을 무장한다.
- Codex 탭: 플랜·결제일 줄 오른쪽에 기호 · 상태 글(확인 안 됨은 "구독 확인 안 됨", 해지 계열은 한 줄 요약) · 펼침 표시. 플랜 버튼은 그 폭만큼 좁힌다. 펼치면 행 아래 100pt에 같은 세 줄과 처리 버튼. 해지 확정 계정은 목록 아래 "해지 확정 N · 순환·재인증 제외" 묶음에 30pt 짧은 행(점 · 이름 · 종료일·근거 · "구독 기록 ⌄")으로 모은다.
- 처리 버튼(상태별): 구독 중·확인 안 됨 → "해지했다고 기록"(ghost), 해지 예약·종료일 지남 → "종료로 확정"(primary) · "종료일 고치기"(ghost) · "기록 지우기"(quiet), 해지 확정 → "기록 지우기 · 구독 중으로"(quiet). 폭이 모자라면 뒤쪽부터 숨긴다.
- 확인 한 번: "종료로 확정"·"기록 지우기"는 첫 클릭에 제목이 "한 번 더 눌러 확정/지우기"로 바뀌고 4초 안에 다시 눌러야 실행한다(대화상자 대신).
- 해지 기록·종료일 고치기 입력은 대화상자다: 종료일(모름 · 결제일 M/D · 날짜 입력) 세그먼트와 날짜 칸, 근거(사용자 확인 · 청구 화면 · 확인 메일) 세그먼트. "바로 종료로 확정"도 한 번 더 눌러야 한다.
- 처리 중인 계정의 버튼은 잠근다. 결과는 하단 막대 왼쪽에 6초: 점(성공 mint · 실패 ember) · 결과 문장 · 성공이면 "되돌리기" 테두리 버튼. 그동안 탭 요약을 가린다.
- 개요 손볼 것: 해지 기록 + 인증 오류 → "종료로 확정"(primary, 그 행으로 가서 무장), 해지 확정 → 빠짐, 조직 차단 → "구독 확인" 그대로, 기록 없는 인증 오류 → "재인증" + 사유에 "다시 로그인해도 안 풀리면 해지 기록". Codex 해지 계정에는 "다시 켜기"를 권하지 않는다.

## 언어

화면 문구는 `Sources/L10n.swift` 한 곳에 있다. 시스템 선호 언어의 첫 항목이 `ko`로 시작하면 한국어, 아니면 영어다. 시험용으로 `CC_MENUBAR_LANG=ko|en`이 이를 덮는다. 한국어는 A안 문구를 따르고, 영어는 짧은 UI 문구로 쓴다. 새 문구를 코드에 직접 쓰지 않는다.
