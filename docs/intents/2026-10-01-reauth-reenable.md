# 재인증 뒤 계정 비활성 상태 재발 방지

Status: accepted — 사용자 지시: “재발 방지해줘” (2026-10-01).

문제: 오래된 비활성/조직 차단 표시가 있는 계정은 `reauth`가 로그인 전에 거절한다. 사용자는 수동 enable 및 subscription ok를 먼저 수행해야 하며, 활성화 표시만으로 실제 인증 복구를 판단할 수 없다.

결과: 명시적인 CLI 재인증이 같은 계정의 신선한 인증 정보로 성공하면 기존 비활성 표시를 해제한다. 실패 시 설정을 유지하고 로그인 도중 새로 생긴 비활성 표시를 덮어쓰지 않는다.

영향/제약: OAuth 인증 복구 경로만 변경. 일반 login/import 및 TUI 노출 정책, 토큰 엔드포인트, upstream 조직 권한, 다른 계정은 변경하지 않는다. 실제 조직 권한이 거부되면 기존 격리 로직이 재적용된다.

열린 질문: 없음. 과거 토큰의 자연 만료/폐기 자체를 방지하는 범위는 아니며, 필요한 브라우저 인증은 사용자가 수행한다.
