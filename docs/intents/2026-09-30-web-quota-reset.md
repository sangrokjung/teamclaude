# 웹 사용량 리셋 반영

Status: accepted — 사용자의 2026-09-30 장애 수정 요청.

- 문제: Claude 웹에서 리셋된 계정이 로컬 quota 100% 때문에 라우팅과 자동 측정 양쪽에서 제외된다.
- 결과: 검증된 최소 probe로 외부 리셋을 발견하고 정상 계정이 자동 복귀한다.
- 영향: Anthropic warm-up, 기존 설정 기본값 5분 주기. 계정당 주기별 최대 1회의 최소 요청.
- 제약: 기존 인증·비활성화·동시성·Codex 동작 유지, 실제 응답 전 quota 초기화 금지.
- 열린 질문: 없음. 운영에서 직접 HTTP 200/주간 0%인 계정과 로컬 100% 불일치를 확인했다.
