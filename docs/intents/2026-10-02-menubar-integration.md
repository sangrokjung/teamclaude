# 메뉴바 단일 저장소 관리

- Status: accepted
- 발의: 사용자가 teamclaude 폴더에서 cc-menubar를 함께 관리하고, 무거운 별도 데스크톱 대시보드는 관리하지 않겠다고 명시했다.
- 문제: 프록시/TUI와 메뉴바의 소스가 서로 다른 저장소에 있어 상태 소비 코드와 운영 빌드가 어긋난다.
- 결과: 이 저장소의 `menubar/`가 네이티브 메뉴바와 클릭 대시보드의 관리 정본이 된다.

- 열린 질문: 없음. 기존 데스크톱 저장소·앱 삭제는 이번 범위에 포함하지 않는다.
