# Intent: 메뉴바 Claude 풀에 계정별 리셋 시각과 재연동 버튼

Status: accepted (2026-11-18, 발의자=대표, web-lab 시안 A안 선택 "A안이 좋다")

## 문제 (발의자 말 그대로, 2026-11-17)

"아래 문제 해결하자
- 지금 팀클로드에 계정이 안들어오고 있는거 재연동 해야함
- 클로드 섹션쪽에 각 계정이 언제 리셋이 되는지 바로 대시보드에 보여야함 웹랩으로 진행
- 대시보드에 재연동 기능이나 버튼이 있어야함 이것도 웹랩으로 한번에 위내용이랑 같이 진행"

## 확인된 사실

계정은 빠지지 않았다. 21개 OAuth 토큰 정상, 20개가 주간 한도 100%. 재로그인은 주간 한도를 풀지 못한다. 대시보드가 계정별 리셋을 행을 펼쳐야만 보여 줘서 "안 들어온다"로 보였다.

## 제안 결과

- 각 계정이 언제 풀리는지 표에서 바로 보인다.
- 대시보드에서 계정을 골라 재연동(OAuth 다시 로그인)할 수 있다.

## 영향

메뉴바 앱(`menubar/`)만. 프록시·설정 파일 형식은 그대로.

## 제약

메뉴바 창 폭 520pt. 문구는 한/영 쌍(L10n). 재연동은 기존 `teamclaude reauth` 경로를 쓴다.
