# 메뉴바 "모델" 탭

- Status: accepted (대표 2026-11-02, 웹 시안 b안 선택 후 2차 수정본 확정)
- 발의: 대표가 전체 에이전트 시스템이 어떤 모델을 얼마나 쓰는지(Claude·Codex, 출처별, 주차별)와 Codex 용량 현황을 메뉴바에서 바로 보고 싶다고 했다. 웹랩 시안 두 개 중 b안을 골랐고, 판정·권고 문구를 뺀 2차 수정본이 기준이다.
- 문제: 지금 메뉴바는 계정 풀(쿼터)과 ccusage 비용만 보여 준다. 모델별·출처별 사용량(Claude Code, Codex CLI, Codex 적대 검증, Codex 구현 루프, Hermes)은 손으로 로그를 훑어야 알 수 있고, Codex 수요가 Pro 몇 계정분인지 가늠할 화면이 없다. 로그는 수 GB라 메뉴바 프로세스가 직접 읽으면 패널이 멈춘다.
- 제안 결과:
  1. 저장소 `scripts/`에 표준 라이브러리만 쓰는 증분 수집기를 두고, 결과 JSON을 캐시 경로에 쓴다. 메뉴바는 그 JSON만 읽는다.
  2. 패널에 6번째 탭 "모델"을 더한다. 기간(7일·14일·전체) × 지표(호출·출력 토큰·전체 토큰), 레인별 큰 숫자, 출처별 목록, 날짜별 쌓은 막대, 모델별 목록, 계정 풀 주간 사용률, Claude 5시간 소진 이력.
  3. 기록이 지워진 구간은 빗금과 경고로 밝히고, 추정값에는 "추정"·"하한" 표기를 붙인다. 구매 판정·권고는 넣지 않는다.
- 영향: 메뉴바에 탭 하나와 숫자 키 6이 늘어난다. 수집기 LaunchAgent는 설치 명령을 따로 실행해야 생긴다(자동 설치 없음).
- 제약: 런타임 의존성 추가 금지, 계정 이메일·토큰·대화 내용은 결과에 넣지 않는다(순번 표기), 공개 저장소 게시 경계 유지, 운영 앱 설치·프록시 재시작 없음.
- 열린 질문: 없음.
