# 큰 작업은 클라우드 크레딧 먼저, 없으면 로컬

Status: accepted

## 문제
대표 발화(2026-10-18): "자동으로 그런 상황일때 클라우드로 쓰게 하고 크레딧 없으면 로컬에서하고"
클라우드 인계(PR #66·#67)는 풀이 완전히 소진됐을 때만 동작한다. 풀이 한 계정이라도 남아 있으면 크레딧은 쓰이지 않고, 크레딧은 만료일에 사라진다. 반대로 로컬 주간 한도는 계속 바닥난다.

## 제안 결과
저장소 안에서 끝나는 큰 개발 작업은 착수 전에 클라우드 세션으로 보낸다. 크레딧이 남은 계정이 없거나 조건이 안 맞으면 로컬에서 그대로 진행한다.

## 영향
Claude Code 세션의 작업 착수 흐름(하네스 규칙), 클라우드 크레딧 소비

## 제약
- 시크릿은 지시문·스냅샷 어디로도 나가지 않는다(PR #66 스캐너 재사용).
- 보냈는지 불확실하면 로컬에서 중복 실행하지 않는다.
- 클라우드 세션은 PR까지만, 교차 검증·머지는 로컬이 한다.
