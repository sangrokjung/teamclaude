# 막힌 Claude 계정을 메뉴바에서 바로 푸는 버튼

Status: accepted
발의: 대표 (2026-11-10 대화)

## 문제 (발의자 언어)

"지금 이 계정 정상적으로 구동중인데 이렇게 나온다. 이 문제 해결하고 상태바 앱에서도 이 문제를 해결할 수 있게 해줘.
버튼 클릭하면 계정 재연동을 한다든가." 메뉴바 손볼 것에 `조직차단 · 조직이 구독을 막아 둠 · 재인증으로 풀리지 않음`이
떠 있었고 버튼은 "구독 확인"뿐이었다. 확인해 보니 원인은 그 계정의 결제 미납이었다("내가 test그 계정에는 결제를 안해놔서
사용이 안되는거였네").

## 제안 결과

- 버튼 하나로 지금 상태를 다시 확인하고, 풀렸으면 바로 라우팅에 복귀한다.
- 결제 연체면 결제 화면을, 토큰 문제면 재연동(재인증) 창을 연다.
- 화면 문구가 결제 연체 가능성을 말한다.

## 영향

TeamClaude CLI(새 `recheck` 명령)와 메뉴바 손볼 것 카드. 서버 라우팅 로직은 바뀌지 않는다.

## 제약

토큰 갱신은 실행 중 서버만 한다. 외부 결제·구독 변경은 하지 않는다(화면을 열기만 한다).
