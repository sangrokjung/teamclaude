# 실행 중인 세션에도 클라우드 인계 적용

Status: accepted

## 문제
대표 발화(2026-10-15): "지금 실행되고 잇는세션에도 적용이 되야돼"
PR #66(풀 소진 시 클라우드 인계)을 운영에 반영했지만, 이미 떠 있는 `teamclaude run` 세션은 예전 코드로 돌고 있다. 그래서 한도에 걸리면 여전히 로컬에서 기다리고 클라우드 크레딧을 쓰지 않는다.

## 제안 결과
지금 실행 중인 세션도 한도에 걸리면 클라우드 세션으로 넘어간다. 평소에는 아무 세션도 끊기지 않는다.

## 영향
떠 있는 Claude 세션 약 30개, 클라우드 크레딧 소비

## 제약
- 소진이 아닐 때는 세션을 절대 건드리지 않는다.
- 시크릿 방어는 PR #66과 동일하게 적용한다.
