## 구현 기록 (Phase 2, 2026-10-25)
계획과 다르게 간 곳과 이유. 시안과 나란히 볼 PNG는 `menubar/.build/`(커밋하지 않음)에 만든다.
- 소진 탭의 "주간 창 타임라인"과 개요의 타임라인 미리보기는 옮기지 않았다. 시안의 타임라인은 계정별 "한도 도달까지 남은 시간"(가장 빠름·평균·가장 느림)을 새로 계산해 그리는데, 이 계획의 원칙("데이터·계산·로더는 바꾸지 않는다")과 충돌한다. 같은 자리에 기존 SubscriptionBurnModel의 레인별 전망·판정 문구를 그린다.
- ⌘K 동작 목록의 검색 칸은 넣지 않았다. 메뉴 추적 중에는 커스텀 뷰가 키 입력을 받지 못한다. 목록은 마우스로 고르고, 단축키(R·1–5·⌘K·⌘Q)는 키 등가를 가진 높이 1pt 메뉴 항목으로 받는다(오프스크린 스냅샷으로는 검증 불가, 실제 메뉴 확인 필요).
- 시안의 Claude 행 동작 "끄기"·"다시 켜기"는 넣지 않았다. 현재 앱에 Claude 계정 켜기/끄기 동작이 없어 새 기능이 된다(Codex 풀의 "다시 켜기"는 그대로 있다). 손볼 것 카드의 꺼 둔 Claude 계정은 버튼 없이 사유만 보인다.
- 시안의 "조직 차단 → 구독 확인" 버튼은 기존 구독 기록 대화상자를 연다.
- 열 머리의 리셋은 살아 있는 계정 중 가장 빠른 리셋이다. 계정마다 창이 달라 값이 다르면 행을 펼쳐 창별 리셋을 본다.
