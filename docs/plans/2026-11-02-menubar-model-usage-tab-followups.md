## Important
- **I1. 옛 형식 Codex 사용량 기록 누락**: 기존 Codex 로더(`CodexStatusLoader.swift`)가 지원하는 사용량 기록 형식을 새 수집기(`scripts/model-usage-collector.py`)가 버린다. 기본 세션 디렉터리에서 재현된다.
- **I2. 요금제·한도 종류 혼합**: Pro 200 기준값 표본에서 `plan_type`·`limit_id`를 구분하지 않아, 다른 요금제 세션이 섞이면 기준값과 수요 환산이 왜곡된다. 기존 로더는 둘을 따로 다룬다.

## Minor (조건부 포함)
- M1. 원본 로그를 정리한 뒤 재계산하면, 보존해 둔 영수증 토큰이 줄어든다.
- M2. 과거 로그의 날짜를 현재 UTC 오프셋으로 계산한다(서머타임 등).
- M3. 새 집계 함수가 함수 길이 기준을 넘는다.
