# 메뉴바 Claude 풀: 계정별 주간 리셋 즉시 표시 + 재연동 버튼

- Intent: docs/intents/2026-11-18-menubar-weekly-reset-relink.md

Status: APPROVED (2026-11-18, 대표가 web-lab 시안 A안 선택)

## 배경

진단(2026-11-17 23:10): Claude OAuth 21개 모두 토큰 정상, 프록시와 설정 40/40 일치. 20개가 주간 한도 100%(`unified7d=1`, `rejected`)라 쓸 수 있는 계정이 1개뿐이었다. 재로그인은 주간 한도를 풀지 못한다. 그런데 표는 계정별 리셋을 행을 펼쳐야만 보여 줘서 "계정이 안 들어온다"로 읽혔다.

시안: web-lab 2안(내부 시안 작업 폴더), 대표가 A안(리셋 일정 + 계정별 리셋 표 + 행·전체 재연동)을 골랐다. 메뉴바 창은 520pt라 A안(900px)을 그대로 옮기지 않고 요소를 기존 표에 녹였다.

## 목표 (Acceptance)

1. 구독(OAuth) 계정 행은 펼치지 않아도 2행에 주간 리셋 시각(로컬 시간대 `M/d(E) HH:mm`)과 남은 시간을 보인다. 사유가 있는 행은 사유 뒤에 붙인다. API 키·구독 종료·지난 리셋은 보이지 않는다.
2. "한도 대기" 묶음은 주간 리셋이 빠른 순으로 놓는다. 다른 묶음과 높이는 바뀌지 않는다. 높이·배치·그리기 4곳이 같은 키를 쓴다.
3. 한도 대기 안내 띠는 주간 한도 계정이 있으면 "다음 리셋 <시각> (<남은 시간> 뒤[, N개]) · 모두 복귀 <시각>"을 쓴다.
4. 띠 오른쪽 "재연동 ▾" 메뉴: 켜진 Claude OAuth 계정 전부(재인증 필요 먼저, 그다음 리셋 빠른 순). 고르면 기존 재인증 경로(`teamclaude reauth <name> --account-uuid`)를 연다. 메뉴 첫 줄에 "주간 한도는 리셋 시각에 풀림"을 밝힌다.
5. 펼친 행에 "재연동" 버튼(재인증이 필요한 행은 기존 "재인증" 버튼이 있으므로 제외). 구독 처리 버튼 뒤에 둔다.
6. 실행 판정 `teamClaudeCanRelink`: 켜짐 + OAuth + anthropic + `subscription-disabled` 아님. 오류 계정 전용 `teamClaudeCanReauthenticate`(상태 칸 버튼)는 그대로.

## Non-goals

- A안의 7일 계단 그래프·요약 카드 3개는 520pt 창에 넣지 않았다(띠 한 줄로 대체). 필요하면 후속.
- "전체 재연동"(모든 계정 동시 로그인)은 만들지 않았다. 계정마다 브라우저 OAuth 창이 떠서 동시 실행은 쓸 수 없고, 주간 한도도 풀지 못한다. 메뉴에서 하나씩 고른다.
- 프록시 코드는 바꾸지 않는다.
